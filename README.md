## Development

```bash
pnpm install
pnpm dev      # local preview (VitePress dev server)
pnpm build    # static build to .vitepress/dist
pnpm deploy   # build + wrangler deploy (Cloudflare Workers static assets)
```

## About remix-editor

remix-editor is a web application for visually editing time-based curves and controlling compatible devices.
