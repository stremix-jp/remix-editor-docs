# Waveform Library

A feature for saving frequently used waveforms as snippets and reusing them. Build up a stock of motion patterns you like and reuse them in other places and other works.

In the default layout it is a tab in the same group as Throttle Control. If the panel is not visible, show it with **View > Panels > Waveform Library**.

## Saving a Waveform

1. Select the range you want to save in the Curve Editor
2. Choose "Save to Library..." from the context menu
3. Give it a name, pick a destination folder, and save

## Using a Waveform

- Choose "Paste" on an item in the Waveform Library panel to paste it at the **current playback position**

The clipboard is shared with the Curve Editor's copy/paste.

## Organizing

- Folders can be created, renamed, and deleted
- Items can be moved between folders by drag and drop

## Exchanging as a File

The whole library can be exported to and imported from a file. Use it to migrate to another environment or to share it.

- **File > Export Waveform Library...** — downloads as `waveform-library.wavelib.json`
- **File > Import Waveform Library...** — loads `.wavelib.json` / `.json`

The same operations are available from the Waveform Library panel menu.
