## Open it in a browser

remix-editor is a web app that runs in the browser. No installation and no account are needed. Open the URL and it is ready.

Supported browsers are the latest Chrome / Firefox / Edge / Safari. The editor has many panels, so a PC with a wide screen is recommended.

## Two ways to open it

There are two ways to open remix-editor, and which one you use changes how the audio is provided and where your work is saved.

| How you open it | Audio & sections | Where it saves |
|-----------------|------------------|----------------|
| **From the production management system (CMS)** | The chapter's audio, section data, and any work in progress are **already loaded** | The on-screen "Save" button saves directly to the server |
| **By opening the URL directly** | You load an audio file yourself | Downloaded as a file |

When opened from the CMS there is nothing to hunt for and load. If the audio waveform and the sections (transcript) are on screen when the editor opens, you are ready.

::: tip
Everything in this course applies when opened from the CMS as well. The only difference is lesson 9, "Saving".
:::

## Loading audio yourself

If you opened the URL directly, load an audio file first.

1. **Drag and drop** the audio file anywhere on the app
2. Or choose **File > Load Audio...** from the menu and pick the file

Supported formats are MP3 / WAV / M4A / OGG / FLAC / AAC, with a 100MB size limit.

If the audio length and the Remix length (max time) differ by 3 seconds or more, an "Adjust Remix length" dialog appears. Normally it is fine to match the audio length.

## The state right after opening

The first time you open it there are no patterns (places to put curves) at all. To draw a curve you first create a pattern, which is lesson 4. Before that, lessons 2 and 3 cover reading the screen and playing audio.
