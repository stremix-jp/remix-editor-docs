# 3. 再生と移動、ズーム

カーブを描く前に、音声を聞きながら **好きな場所へ移動し、好きな倍率で見る** 操作を覚えます。制作中はこれらを何百回と繰り返します。

## 再生と一時停止

- **Space** キー、またはフッターの再生ボタンで再生と一時停止を切り替えます
- どのパネルが選ばれていても Space は効きます（文字入力中を除く）

## 再生位置を動かす（シーク）

再生位置は、カーブエディタに縦線（再生ヘッド）として表示されます。動かす方法は 3 つあります。

| 方法 | 使いどころ |
|------|-----------|
| フッターのシークスライダーをドラッグ | 大まかに移動する |
| カーブエディタ上部の再生ヘッド領域をクリック / ドラッグ | 画面に見えている範囲の中で正確に合わせる |
| セクションパネルの行をクリック | その場面の頭に一気に飛ぶ（5 回目で扱います） |

## ズームとパン

カーブエディタの表示範囲（ビューポート）は自由に動かせます。

| 操作 | 動作 |
|------|------|
| マウスホイール | カーソル位置を中心にズームイン / アウト |
| 右ドラッグ | 表示範囲を左右に動かす（パン） |
| **J** キー | 現在の再生位置へ表示範囲をジャンプさせる |
| **F** キー | 「再生位置を追尾」の切り替え。ON にすると再生中に表示範囲が自動で追いかけます |
| ツールバーの「全体表示」 | Remix 全体が収まる倍率に戻す |

編集中に再生位置を見失ったら **J** を押す、と覚えておくと楽です。

## 再生速度を変える

フッターの速度表示（1x）をクリックすると、0.25x 〜 2x の中から選べます。**Shift + >** / **Shift + <** でも切り替えられます。

- 細かいタイミングを確認するときは 0.5x や 0.75x に落とします
- 全体を流して確認するときは 1.5x や 2x にします

## 同じ区間を繰り返し聞く（ループ）

1. カーブエディタで **Shift + ドラッグ** して時間範囲を選択します
2. フッターのループボタンを ON にします

選択範囲がある間はその範囲だけを繰り返し再生します。選択範囲がなければ全体をループします。フッターの「選択範囲の先頭から再生」ボタンを押すと、選択範囲の頭から再生が始まります。

## 練習

音声を通しで 1 回聞きながら、場面が変わるところで一時停止し、その位置へ再生ヘッドを合わせる練習をしてください。ズームして正確に合わせ、**J** で戻る、を繰り返します。
