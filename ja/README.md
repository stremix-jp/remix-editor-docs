# remix-editor ユーザーガイド

remix-editor は、時間軸に沿った値の変化（カーブ）を視覚的に編集し、対応デバイスを制御するための Web アプリケーションです。

このガイドは 2 部構成です。初めての人は **基礎講座** を 1 回目から順に読んでください。これだけで Remix を 1 本作れます。**リファレンス** は機能ごとの説明で、必要なときに引きます。

## 基礎講座

作る順番どおりに 10 回で進める講座です。

1. [エディタを開く](./basics/01-open.md) - 2 つの開き方と音声の読み込み
2. [画面の構成](./basics/02-screen.md) - 制作で使う 5 つのパネル
3. [再生と移動、ズーム](./basics/03-playback.md) - 再生・シーク・ズーム・ループ
4. [パターンを用意する](./basics/04-patterns.md) - パターンの追加と必須の設定
5. [セクションを読む](./basics/05-sections.md) - 文字起こしの確認・場面へのジャンプ・メモ
6. [波形を生成する](./basics/06-generate.md) - 三角波を範囲にまとめて生成する
7. [手で調整する](./basics/07-adjust.md) - 打点・移動・選択範囲のリサイズ・数値編集
8. [プレビューする](./basics/08-preview.md) - 画面と実機での確認、速度カラーリング
9. [保存する](./basics/09-save.md) - CMS への直接保存とファイル保存
10. [デバイス別の作り方の基本](./basics/10-by-device.md) - リニア・振動・回転の違いと 1 本仕上げる流れ

## 動作環境

- モダンブラウザ（Chrome, Firefox, Edge, Safari）
- デバイス制御には [Intiface Central](https://intiface.com/central/) が必要
- インストールやログインは不要です。編集内容はブラウザ内に自動保存されます
