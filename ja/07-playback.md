# 再生操作

remix-editor では音声を再生しながらパターンをプレビューできます。デバイスが接続されている場合、リアルタイムで制御されます。

## 音声ファイルの読み込み

### ドラッグ＆ドロップ

1. 音声ファイルをフッターのメディアエリアにドラッグ
2. ドロップして読み込み

音声ファイルはアプリケーション上のどこにドロップしても読み込まれます。

### ファイル選択

1. メディアエリアをクリック
2. ファイル選択ダイアログから選択

メニューの **ファイル > 音声を読み込み...** からも選択できます。

### 対応形式

| 形式 | 拡張子 |
|------|--------|
| MP3 | .mp3 |
| WAV | .wav |
| M4A | .m4a |
| OGG | .ogg |
| FLAC | .flac |
| AAC | .aac |
| WebM | .webm |

**ファイルサイズの上限は 100MB** です。超えると「ファイルサイズが大きすぎます（最大100MB）」と表示され、読み込まれません。

### 自動復元

読み込んだ音声ファイルはブラウザ（IndexedDB）に保存され、次回起動時に自動的に復元されます。

ただし、**設定 > 一般 > 音声キャッシュ上限**（デフォルト 50MB）を超えるファイルは保存されず、リロードすると消えます。上限を `0` にするとキャッシュが無効になります（無制限ではありません）。

### Remix の長さの調整

読み込んだ音声の長さと Remix の最大時間が 3 秒以上ずれている場合、「Remixの長さを調整」ダイアログが表示されます。

- **調整する**: 最大時間を音声の長さに合わせて延長/短縮します
- **調整しない**: 現在の最大時間を維持します

短縮する場合は、削除されるポイント数が警告として表示されます。

## 再生コントロール

フッターのトランスポートで操作します。

| ボタン | セクションなし | セクションあり |
|--------|----------------|----------------|
| 左端 | 先頭へ | 前のセクションへ |
| 中央 | 再生 / 一時停止 | 再生 / 一時停止 |
| 中央右 | 選択範囲の先頭から再生 | 選択範囲の先頭から再生 |
| 右端 | 末尾へ | 次のセクションへ |

### 再生/一時停止

- **Space** キーまたは再生ボタン
- 再生中に押すと一時停止
- 一時停止中に押すと再生再開

### シーク（再生位置の移動）

- フッターのシークバーをドラッグ（**時間ステップにスナップ**します）
- カーブエディタの再生ヘッド領域をクリック / ドラッグ
- セクションテーブルの行をクリック（そのセクションの開始位置へ移動）

## 再生速度

### 速度変更

フッターの速度表示をクリックすると、速度の一覧から選択できます。

| 速度 | 用途 |
|------|------|
| 0.25x | 細かい確認 |
| 0.5x | スロー再生 |
| 0.75x | やや遅め |
| 1x | 通常速度 |
| 1.25x | やや早め |
| 1.5x | 早め |
| 2x | 2倍速 |

### ショートカット

- **Shift + >**: 速度アップ（循環）
- **Shift + <**: 速度ダウン（循環）

最大/最小で折り返します。

## 音量

### 音量調整

- 音量スライダーで 0% 〜 100% の範囲で調整
- ミュートボタンで即座に消音

## リピート再生

### リピートモード

ループボタンをクリックすると、ループ再生が有効になります（有効時はボタンが強調表示されます）。

### ループ範囲

| 条件 | ループ範囲 |
|------|------------|
| 選択範囲あり | 選択範囲 |
| 選択範囲なし | 全体（音声の長さ、または最大時間） |

リピート中は、終端に達すると自動的に開始位置に戻ります。

## ピボット機能

ピボットは「お気に入りの位置」のようなものです。頻繁に戻る位置を記憶しておけます。ピボットは**複数登録**できます。

### ピボットを追加

- **P** キーを押す
- 現在の再生位置がピボットとして**追加**されます（既存のピボットは消えません）
- ほぼ同じ位置（±0.001秒以内）にはピボットは追加されません

削除はカーブエディタのツールバー、またはコンテキストメニューの「ピボットを削除」「選択範囲のピボットを削除」から行います。

### ピボット間の移動

| キー | 動作 |
|------|------|
| Shift + P | 次のピボットへ（末尾まで行くと先頭へ循環） |
| Ctrl + Shift + P | 前のピボットへ（先頭まで行くと末尾へ循環） |
| Ctrl + P | 選択中のピボット位置へ再生位置を移動 |

### ドラッグでの移動

カーブエディタの再生ヘッド領域に表示されたピボットは、ドラッグで位置を変更できます。

### 永続化

ピボット位置は自動的に保存され、次回起動時にも維持されます。Undo の対象で、Remix ファイルにも保存されます。

## 再生位置操作

### 再生位置へジャンプ

- **J** キー
- ビューポートが現在の再生位置に移動します
- 編集中に再生位置を見失った時に便利

### 再生位置を追尾

- **F** キー、またはカーブエディタのツールバーから切り替え
- 有効にすると、再生に合わせてビューポートが自動的にスクロールします
- デフォルトは無効。**設定 > 再生 > 再生位置を追尾** でも変更できます

### 打点へのジャンプ

| キー | 動作 |
|------|------|
| Alt + → | 次のポイントへ再生位置を移動 |
| Alt + ← | 前のポイントへ再生位置を移動 |
| N | 次のポイントを選択 |
| B | 前のポイントを選択 |

### 再生ヘッドのドラッグ

カーブエディタ上部の再生ヘッド領域をドラッグして再生位置を変更できます。

### 再生ヘッドオフセット

音声とデバイスへの送信タイミングにオフセットを設定できます。

- デフォルト: **0.2秒**
- 範囲: -1秒 〜 +1秒（正の値でデバイスが先行、負の値で遅延）
- 用途: デバイスの応答遅延を補正

**設定 > 再生 > 再生ヘッドオフセット** で変更できます。

## 選択範囲再生

### 選択範囲の先頭から再生

1. カーブエディタで範囲を選択
2. フッターの「選択範囲の先頭から再生」ボタンをクリック
3. 選択範囲の開始位置から再生が開始されます

選択範囲がない場合、このボタンは無効です。

### セクションからの再生

セクションテーブルの行をクリックすると、カーブエディタの選択範囲がそのセクションに設定され、同時に再生位置がセクションの開始位置へ移動します。あとは Space キーで再生できます。

詳しくは [セクション](./05-sections.md) を参照してください。

## 背景波形表示

カーブエディタの背景に音声の波形を表示できます。

### 設定

1. **設定 > カーブエディタ** を開く
2. 「波形背景を表示」を有効化（デフォルトで有効）

### 調整項目

| 設定 | 説明 | デフォルト |
|------|------|-----------|
| 波形自動スケーリング | 画面内の最大値に合わせて自動調整 | 有効 |
| 波形倍率 | 波形の高さ（%） | 50% |
| 波形サンプル数 | 波形の解像度（50 〜 4000） | 2000 |

サンプル数を増やすと詳細になりますが、処理が重くなります。

## スロットル制御

再生中にリアルタイムで値を入力できる機能です。専用の「スロットル制御」パネルで操作します。

デフォルトのレイアウトでは「波形ライブラリ」と同じグループのタブになっています。パネルを閉じてしまった場合は **表示 > パネル > スロットル制御** で再表示できます。

### 使い方

1. アクティブなパターンを選択
2. 再生を開始
3. 縦スライダーを掴んでドラッグ

- スライダーを掴んだ時点で、現在の再生位置にポイントが1つ追加されます
- **再生中のみ**、ドラッグ中の値が時間ステップ間隔で連続的に記録されます
- 値は 0 〜 1 の割合として扱われ、パターンの最大値に掛けた値が記録されます
- ドラッグを離すと、その一連の記録が Undo 1回分にまとめられます

ライブ入力に便利です。

## デバイスとの同期

再生中、パターンの値は自動的に接続されたデバイスに送信されます。パターンの**出力が有効**（電源アイコン）になっている必要があります。

### アクチュエータータイプによる違い

| タイプ | 動作 |
|--------|------|
| 振動（Vibrate） | 即時制御（値が直接強度になる） |
| 回転（Rotate） | 即時制御（正負で回転方向が変わる） |
| ピストン（Linear） | 位置ベース（指定位置まで移動する時間を伴う） |

## トラブルシューティング

### 音声が再生されない

1. ブラウザのミュートを確認
2. 音量スライダーを確認
3. 対応形式のファイルか確認
4. ファイルサイズが 100MB を超えていないか確認

### リロードしたら音声が消えた

**設定 > 一般 > 音声キャッシュ上限**（デフォルト 50MB）を超えるファイルは保存されません。上限を引き上げるか、都度読み込み直してください。

### 再生がカクつく

1. 背景波形のサンプル数を減らす
2. 他のタブを閉じる
3. ブラウザを再起動

### デバイスと音声がずれる

1. **設定 > 再生 > 再生ヘッドオフセット** を調整
2. デバイスの遅延特性を確認
